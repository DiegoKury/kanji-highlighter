# Kanji Highlighter

**Kanji Highlighter** is a Chrome extension for Japanese learners. Highlight any Japanese word on a webpage to instantly see its reading with pitch accent and English meaning from [Jisho.org](https://jisho.org).

[Chrome Web Store](https://chromewebstore.google.com/detail/kanji-highlighter/jimnldmbimiecphmfncjenhbkgcagebp)

---

## Features

- **Instant Lookup** — Highlight any Japanese word to get a popup with its reading, pitch accent, and meaning.
- **Pitch Accent Display** — Pitch contour is shown visually on the reading using overlines, underlines, and step markers, sourced from [OJAD](http://www.gavo.t.u-tokyo.ac.jp/ojad/).
- **Context Menu Search** — Right-click selected text and choose **"Search Kanji on Jisho.org"** to open the full dictionary entry in a new tab.
- **Enable/Disable Toggle** — Turn the highlighter on or off from the extension popup.

---

## Usage

1. Click the extension icon and enable the highlighter.
2. Highlight any Japanese word on a webpage.
3. A popup appears with the word, reading (with pitch accent), and English meaning.
4. The popup closes automatically after 8 seconds, or click × to dismiss it.

## Pitch Accent Notation

| Pattern | Example | Display |
|---|---|---|
| Heiban (0) | 雨 あめ | plain first mora, rest overlined |
| Atamadaka (1) | 箸 はし | overlined first mora with drop, rest underlined |
| Nakadaka (N) | 食べ物 | underline → step-up \| → overline → drop \| → underline |
| Odaka (end) | 男 おとこ | underline → step-up \| → overline → drop at end |
